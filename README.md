# 互动 3D 太阳系 Demo

一个使用 Vite、原生 JavaScript 和 Three.js 构建的轻量浏览器演示。

## 功能

- 中文界面：按钮、提示、星球名称和简介均已中文化，同时保留英文行星名作为辅助识别。
- 太阳、八大行星、地球月球、土星环和轨道路径组成的 3D 太阳系演示。
- 新增“总览”入口：不锁定具体行星，可自由观察整体轨道和主要行星；点击太阳或画布空白处也会回到总览。
- 新增连续时间流速滑块：0x 暂停到 5x 无级调速，实时显示当前倍速；默认 0.5x，便于观察。
- 补完整月球展示：月球围绕地球运行，带独立轨道、中文信息、图例入口，并可通过点击直接选中。
- 提升环境光、太阳光和材质可见度，暗面仍可辨识，同时保留空间层次感。
- 鼠标、触控板和触摸操作支持旋转、缩放；点击行星、月球或图例按钮可聚焦并显示简介。
- 桌面和移动端自适应画布尺寸。

## 本地运行

```bash
npm install
npm run dev
```

打开 Vite 打印的本地地址，通常是 http://localhost:5173/。

## 生产检查

```bash
npm run build
npm run preview
```

构建输出位于 `dist/`。

## 说明

距离和行星半径不是严格真实比例。真实太阳系比例会让内侧行星过小、外侧行星过远，不利于浏览器演示；本项目采用夸张的可视化比例，并在信息面板中保留科普说明。
